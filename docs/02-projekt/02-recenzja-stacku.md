# Recenzja stosu i architektury AquaSmart v2

**Werdykt: Laravel 13 + Filament 5 + Livewire 4 + PostgreSQL, jako jedna aplikacja i jedna baza.** Filament dla operatora i sklepu. Panel akwarysty jako Blade z komponentami Livewire tam, gdzie potrzebna jest interakcja. Publiczne strony w Blade. Największą przewagą jest połączenie gotowych paneli z możliwością przeniesienia aktywnego silnika PHP i sprawdzenia zgodności przed zmianą reguł. Największe ryzyka projektu to odtworzenie błędów pod hasłem zgodności 1:1, pomieszanie uprawnień z publikacją sklepu i uznanie kliknięć za podstawę należności bez zatwierdzonej reguły. `aquawiedza-v2/docs/02-projekt/01-stack-i-architektura.md:20–36`, `aquawiedza-v2/docs/01-analiza/10-silnik-rekomendacji.md:413–422`, `aquawiedza-v2/docs/01-analiza/20-sklep.md:272–284`.
